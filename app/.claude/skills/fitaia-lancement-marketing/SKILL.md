# Lancement & marketing FITAIA (distillé de coreyhaines31/marketingskills, MIT)

## ASO (App Store / Play) — règles dures
- Apple : titre ≤ 30 car., sous-titre ≤ 30, champ mots-clés 100 octets, séparés par des virgules sans espace, aucun mot répété entre titre/sous-titre/mots-clés. La description longue n'est PAS indexée : l'écrire pour convertir. Les légendes de captures sont indexées ; les 3 premières captures apparaissent dans la recherche.
- Google Play : description courte 80 car., longue 4 000 car. indexée (densité 2–3 %), pas de « meilleur / n°1 / gratuit », pas d'emoji ni de majuscules dans le titre. Crash > 1,09 % ou ANR > 0,47 % pénalise la visibilité.
- Toujours signaler : note < 4,0, pas de mise à jour depuis > 3 mois, < 5 captures.
- Score sur 6 axes : titre 20 %, description 15 %, visuels 25 %, notes 20 %, métadonnées 10 %, signaux de conversion 10 %. Comparer à 3 concurrents, lister les gains rapides.
- Jamais inventer de données App Store Connect : si l'accès manque, le dire et travailler sur la fiche publique.

## Lancement — « lancer encore et encore »
- Porte de sortie : Simple, Aimable, Complet. Pas de « mode furtif », pas de « juste une fonctionnalité de plus ».
- Phases : interne → alpha → bêta (TestFlight) → accès anticipé → lancement complet.
- Canaux : possédés (e-mail, in-app) > loués (stores, 1–2 réseaux max) > empruntés (influenceurs, partenaires). Ramener vers le possédé.
- Checklist : avant (page, capture d'e-mails, visuels, analytics) · jour J (e-mail, post, in-app, équipe qui répond) · après (séquence onboarding, relances, pages comparatives, retours).

## Copywriting
- Clair avant créatif. Simple > complexe, précis > vague, actif > passif, affirmé > prudent, montrer > dire, honnête > sensationnel.
- Formules de titre : « {Résultat} sans {douleur} », « L'app {catégorie} pour {public} », « Ne {mauvaise chose} plus jamais ».
- CTA = verbe + ce qu'on obtient (« Créer mon perso »). Livrer 2–3 variantes avec justification.
- Ordre de page : promesse → preuve sociale → problème → solution → comment ça marche → objections → CTA.
- Relire avec le skill fitaia-copy-sans-slop.

## Onboarding & paywall (RevenueCat)
- Valeur avant demande : le paywall arrive après le moment « aha » (perso créé, premier défi réussi), jamais pendant l'onboarding ni au milieu d'un geste, jamais répété après un refus (limite par session + délai de plusieurs jours).
- Déclencheurs : fonctionnalité verrouillée, limite d'usage, fin d'essai (rappels J-7, J-3, J-1).
- Écran : titre bénéfice (« Débloque X pour Y »), aperçu avant/après, comparaison avec le plan actuel, mensuel vs annuel (annuel −17 à −20 %, premium 2–3× le milieu, ancrer par le premium), preuve sociale, CTA précis, « Pas maintenant » visible. Restauration des achats obligatoire (règle Apple 3.1.1).
- Interdit : croix cachée, culpabilisation, compte à rebours factice.
- Mesurer : impressions → CTR → complétion → revenu/utilisateur → churn post-achat.

## Prix
- Valeur perçue = plafond ; alternative suivante = plancher. Métrique de valeur qui grandit avec l'usage. Good-Better-Best avec leurre au milieu. Augmenter si conversion > 40 % ou churn < 3 %.
