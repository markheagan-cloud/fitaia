# Copy sans slop (adapté de hardikpandya/stop-slop, MIT)

## Règles
1. Zéro remplissage : pas d'ouverture qui s'éclaircit la gorge (« Soyons clairs », « La vérité, c'est que », « Parlons de… »), pas de béquilles d'emphase (« Point final. », « Laisse ça infuser. »), pas d'adverbes mous (vraiment, juste, littéralement, sincèrement, simplement, en fait, profondément).
2. Pas de structures formatées : contraste binaire (« Ce n'est pas X. C'est Y. »), liste négative (« Pas un outil. Pas une méthode. Une philosophie. »), fragments dramatiques (« La confiance. C'est tout. »), question rhétorique de lancement, fausse agentivité (« La décision a émergé » → « L'équipe a décidé »).
3. Voix active : un sujet humain qui fait quelque chose. Jamais de passif.
4. Précis plutôt qu'absolu : bannir « toujours », « jamais », « tout le monde » ; donner un chiffre, un exemple, un nom.
5. Ancrer le lecteur : « tu/vous » plutôt que « les gens » ; concret plutôt qu'abstrait.
6. Rythme : varier la longueur des phrases ; deux éléments valent mieux que trois ; pas de tiret cadratin (—) ; pas de « Rapide. Simple. Efficace. ».
7. Respecter le lecteur : dire le fait, sans justification ni enrobage.
8. Supprimer les phrases « citables » : si ça sonne comme une citation d'affiche, réécrire.
9. Jargon interdit : naviguer, déconstruire, game-changer, plonger en profondeur, s'approprier, écosystème, synergie, « au cœur de », « il convient de noter », « en fin de compte », « dans un monde où ».
10. Pas de méta-commentaire : « Plot twist », « Laisse-moi t'expliquer », « Comme on le verra ».

## Checklist avant livraison
- [ ] adverbes · [ ] passif · [ ] sujets inanimés qui agissent · [ ] ouvertures en « Qu'est-ce que / Pourquoi / Alors, / Écoute » · [ ] contrastes négatifs · [ ] phrases toutes de même longueur · [ ] chute « punchline » · [ ] tirets cadratins · [ ] déclaratifs vagues (« les enjeux sont élevés ») · [ ] narration à distance · [ ] méta-commentaire
- Note sur 50 (directness, rythme, confiance, authenticité, densité : /10 chacun). < 35 → réécrire.

## Spécifique FITAIA
- Ton Fito (coach) : phrases courtes, chiffres réels de l'utilisateur, une action à la fois. Pas de « Bravo champion ! » ni d'emoji.
- Textes App Store : bénéfice concret en 1re ligne, jamais « meilleure app », « n°1 », « gratuit » dans le titre.
- Toasts : ≤ 60 caractères, le fait d'abord (« +500 FIT Crédits · défi réussi »).
